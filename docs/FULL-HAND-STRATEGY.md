# 完整牌局策略：条件范围、多人和未来街

## 入口与前提

`FullHandDecisionEngine.analyze(state:hero:cards:ranges:allowedActions:profiles:heroContinuation:configuration:budget:isCancelled:)` 返回 `DecisionResult`。

必须提供完整且可审核的 `TableState`、每名未弃牌对手的范围，以及屏幕真实可用的动作白名单。动作金额是本街累计 `raiseTo`，新增投入在 `ActionEstimate.additionalChips` 中单独返回。白名单不能为空、不能重复，最多 32 个动作，每个动作都通过 `TableState.applying` 的筹码、最小加注和加注权验证。没有完整状态不能借这个接口猜测边池、轮次或加注权。

默认参数为 256 个样本、600 毫秒预算；完整模式最少需要 64 个全部算完的样本。样本数不足会抛出 `budgetExceeded`，不产生动作建议。时间预算包括本次分析初始化；每个候选和策略行动前检查取消与截止时间。初始化及单个原子步骤仍会产生少量预算超时，不是硬实时调度。`minimumSamplesRequired`、`samplesPerScenario`、`completedBudget` 明确报告实际计算状态。

原 `DecisionEngine` 入口保持兼容，默认只完成当前下注轮并将未来街过牌至摊牌；可显式传 `RolloutConfiguration` 启用未来街。两种入口都以等权平均 EV 选动作。

## 单个样本怎么算

1. 从各座位范围独立抽取底牌；有冲突就拒绝整组重抽，避免按座位顺序依次重权造成分布偏差。
2. 对所有候选动作和行为假设完成本街行动，允许对手再次加注后轮到本人继续行动。
3. 本街所有候选完成后再抽未来公共牌。各候选共享同一组底牌、同一公共牌和对应行为随机种子，降低差值噪声；改变候选排列不改变完成固定样本预算时的结果。
4. 完整模式逐街揭示公共牌前缀，按规则重新确定行动顺序。每个策略只接收自己的假设底牌和已经公开的公共牌特征；不读取他人抽样底牌或未发出的后续牌。未来街使用便宜的未训练牌力特征，未执行每个未来节点的全范围穷举。
5. 默认每街最多两次策略加注；之后策略仍可以过牌、跟注或弃牌。首个候选加注也计入本街上限。每街还有 128 个动作的故障边界，超限报错而不制造摊牌结果。
6. 用完整累计投入划分主池、边池、未跟注退款；每个池分别决定有资格的赢家和平局分摊。本人收益 = 本人总派彩 − 从当前时点新增的投入；已经投入的筹码不再重复扣除。
7. 只有所有动作、所有情景都完成后，才提交一个样本。预算中断的一半样本整体丢弃，保证各候选样本数相同。

河牌若公共牌本身不可被任何两张合法底牌改善，默认行为模型不会凭空模拟有人弃掉必然平分的牌。该保护精确覆盖皇家同花顺、带最高可用踢脚的公共四条，以及没有三同花可能的 A 高公共顺子；用常数时间的牌型条件判断，测试再穷举合法底牌核验。普通使用公共牌但仍可能被超过的手牌不受此保护。这是行为模型的逻辑约束，不把平分概率改成独赢概率。

## 选择目标与百分比

`ActionEstimate.expectedEV` 是所列行为假设的等权均值。默认紧、中、松三种是假设，未经真人数据标定；不是三个真实人群的比例，也不是最差情景最大化。`worstScenarioEV` / `bestScenarioEV` 保留用于敏感性审核。

`equity.outrightWinProbability` = 假设所有当前未弃牌者都到摊牌时，本人独自获胜的概率。`tieProbability` 单独报告本人并列获胜的概率；`equity` 是平均分池份额，多人平局按实际赢家人数分配。它们条件于输入的各座位范围，和模拟有人弃牌后的“赢得底池概率”、行动 EV 不同。

行为假设共用同一底牌样本；配对差值区间在每个样本的情景平均收益上计算，不把相关情景误当独立数据。选出的动作与所有候选的比较及提前结束样本数均使用预先分配的联合误差预算。统计区间只涉及抽样误差，不覆盖识别、缺失历史、范围及行为模型误差。

## 不完整下注状态的回退边界

`ResearchDecisionEngine` 只有公开总底池和人数上界，不能知道哪些玩家已经跟齐。在翻前、翻牌、转牌和河牌面对下注时，若没有确认六个其他席位均已弃牌，或者跟注金额已封顶本人余筹/检测到全下，该入口只返回条件概率，不生成弃牌/跟注指令；完整状态入口仍可独立完成分析。已确认的非封顶单挑跟注保留受限比较，确实可免费过牌时仍可以提示过牌，不宣称已比较全部加注。

撤回付费动作时，概率参考结果的 `suggested` 为 `nil`，`withheldActionReason` 给出具体原因；`mainOutrightWinProbability` 等仍可读取。各 `ResearchDecisionScenario.actionValueApplicable == false`，其旧 `passiveValue/preferred` 仅供反事实审计，不能当成此牌局的动作首选。免费过牌可以保留，但多人过牌的反事实 EV 同样标为不可用于排序；它是已确认的零成本动作，不代表下注最优。下注/加注也要求实际六座弃牌证据，不能只传入 `opponentCounts=1` 就视为单挑。不能把未知人数偷偷改为单挑，也不能让尚未跟注的其他玩家免费分摊当前底池。

例如当前总底池 4.50、本人需跟 2.80，并不表示五名对手均已支付 2.80。如果六名玩家都跟到 2.80，最终总池是 16.80，不是 7.30；必须由逐人投入与响应推演计算。对子 QQ、AA 或弱牌适用同一边界，没有特定牌型的强制继续规则。

## 公开行动条件化范围

`PublicActionRangeModel.analyze(hand:prior:profiles:isCancelled:)` 接收 `VerifiedPublicHand`。

- 只有 `actionSequenceUnique` 的历史可以使用。每名玩家当前 `stack + committed` 恢复开手筹码，按显式桌规重新发盲注，再重放所有动作及换街。最终状态必须与已验证状态完全相等。允许全下后的无动作街，以及刚换街但还没有人行动。非唯一、重复、冲突或错误顺序历史会报错，不能悄悄变成已学习范围。
- 动作前底池、跟注成本、加注权由重放恢复，未根据未知值假造压力。
- 按与行为策略相同的弃牌/过牌/跟注/加注类别概率，对行动者本人的范围逐步 Bayes 重权。行为类别概率对所列假设等权平均，加入明确的 2% 类别噪声，避免未校准策略把可行牌完全删掉。
- 加注尺寸用于恢复合法状态和后续跟注压力；不把具体尺寸当作已学习的下注大小模型。策略搜索的每街加注上限不用于判断真人是否可能再次加注。
- 每次从原始先验和唯一历史重算，因此重复截图不会再次累计相同行动。只为当前未弃牌对手返回范围；本人动作不会当作对手牌力证据。当前本人牌、公共牌从所有范围中排除。
- 无有效对手动作时返回随机（或显式给定）先验并清楚标识。有动作时标识“按N次已确认对手行动更新范围（未校准模型）”。这不是经过校准的人类画像，更不能证明对手在诈唬。
- 返回的每座位范围在决策发牌时进一步联合排除碰撞。已弃牌者暗牌分布没有建模。历史最多 128 个事件，逐组组合检查取消；没有另一个内部时间预算，调用者可以通过取消回调施加整个任务的时限。

## 验证与性能边界

独立 release 快照测试：11 条完整策略、7 条动作条件化、5 条原决策/观测测试，共 23/23 通过。测试包括多人短全下边池、退款、royal 公牌多人分池、短全下不重开加注权、再加注回到本人、未来下注影响收益、隐藏信息边界、固定种子与候选顺序、等权目标不同于 maximin、动作白名单、最少样本与取消。

9 人、0.2/0.5/1 第三盲、7 个候选、3 个行为情景、256 个完整未来街样本：本机 release 两次观察约 200–320 毫秒，期间主机负载不同。范围构建、OCR、传输、UI 和 iPhone 性能不包含在这个比较中；不是端到端延迟承诺。避免给每名玩家重复解析相同随机范围，复用一个不可变范围即可。

## 仍未支持的策略含义

未训练的有限 rollout，不是 GTO 或能保证战胜真人的求解器；没有无限次加注、精确未来策略优化、对已弃牌者的暗牌后验、抽水、ICM、保险和特殊奖励。第三盲只支持规则模块明确实现的 UTG 一档第三盲。独立算法可运行不代表任意截图已经能还原完整历史；实际屏幕桥接必须单独报告通过的状态与回退原因。
