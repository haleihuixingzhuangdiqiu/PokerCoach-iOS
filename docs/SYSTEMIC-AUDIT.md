# 系统性策略修复与概率复核

## 已确认的问题

旧局部快照路径在多人待行动、各人本街投入未知时，使用所有可能对手都留到摊牌的权益，乘以“当前底池 + 本人跟注”，再扣本人跟注成本。两项假设互相矛盾：其他人被视为留到摊牌，却无需补齐跟注。该错误会低估继续投入的价值；翻前缺少加注比较，又进一步扭曲强牌选择。不能用“QQ 永远不弃牌”修复。

例：六人、当前投入 `[0, 280, 20, 50, 100, 0]`，底池 450，本人跟注 280。如果其余人全跟、之后免费摊牌，最终底池是 1680，而不是 730。若有人弃牌，最终人数、范围、底池都应随之改变；不能把 1680 又当成必然所得。

## 修复

- 局部快照在所有街撤回上述无依据的付费动作，保留标明假设的条件概率和实际可用的免费过牌。
- 只有确认六个其他座位已弃牌、未识别全下且本人跟注未封顶，才保留受限的单挑比较。
- 完整状态路径逐人模拟补齐、弃牌、再加注、后续街，以及主池/边池与未被跟注款项退回。
- 新增翻前单次开池的快照重建。全部筹码、投入、弃牌、行动者、庄家与桌规必须齐全；同一状态须在两帧确认。任何未排除的第三盲/多次加注解释都会阻断重建。
- 开池重建明确为 `singleOpenSnapshot`、`historyComplete=false`，不冒充连续历史。只对推断的开池者更新范围；其他仍在牌局中的人使用合法先验。
- 未知字段不补零，人数上界不改成单挑；真实屏幕金额之外不发出虚构按钮指令。

## 概率的独立核验

`tools/audit_qq_probability_pokerkit.py` 使用 PokerKit 0.7.4，固定随机种子，生成 100,000 次合法无放回发牌，再按 1–7 名对手的前缀计算；同一批中的不同人数结果相关。Swift 使用另一套抽样器、另一随机种子复核。下表是独立参考输出，包含抽样误差，不能当成特定真人范围下的真值。

| 随机对手数 | QQ 独赢 | QQ 权益（含平分份额） |
| --- | ---: | ---: |
| 1 | 79.74% | 80.03% |
| 2 | 64.84% | 65.10% |
| 3 | 53.48% | 53.74% |
| 4 | 44.70% | 44.98% |
| 5 | 37.84% | 38.14% |
| 6 | 32.32% | 32.65% |

自动测试覆盖这些参考值、指定 QQ 对 AA/AK 的不同范围、跟注价格变化，以及其他玩家补齐跟注后的筹码守恒。QQ 对强范围、极大价格或特殊赛事局势可能合理弃牌；单凭“对 Q”和“4 元”不足以判定正确动作。

## 共享坚果公牌的行为模型修复

复核还发现，旧行为特征把“本人最佳五张牌恰好就是公共牌”统一视为弱牌。这样在公共皇家同花顺等无人能改善的河牌上，默认紧/中/松策略仍可能模拟弃牌，从而给下注虚构弃牌收益。未来街也会遇到这个问题；只用固定跟注模型的测试无法发现它。

现在仅对公共牌自身不可被任何合法两张底牌改善的情况禁止模型弃牌：皇家同花顺、带最高可用踢脚的公共四条，以及没有三同花可能的 A 高公共顺子。采用常数时间的牌型条件，没有在每个模拟河牌重新枚举上千组合；普通使用公共牌但可能被超过的手牌仍可以弃牌。该保护不改变真实牌型评分、独赢率或多人分池公式。

新增 5 个回归检查当前河牌、未来河牌、默认三类行为模型，以及不能被一并放行的普通公共顺子/同花/葫芦/低踢脚四条。正反例还用**项目现有牌型计算器逐个穷举 1,081 种合法底牌组合**核对常数时间判断；这是不同判断路径的交叉验证，**不是另一套独立 evaluator**。5 个新测试加 11 个原完整策略测试均通过。公共皇家同花顺的三人例保持独赢 0、并列 1，各下注候选均无虚构额外收益，等值时选择免费过牌。

## 仍需完成的验收

这些修复不等于已训练出长期盈利策略。默认紧/中/松是未校准的行为假设；模拟动作收益仍依赖它们。牌桌识别和连续状态覆盖存在明显缺口，原生手机也需要单独验证。算法测试、Mac 录像回放、iPhone 组件回放、实际 ReplayKit/PiP 连续对局分别是不同层次的证据，不能相互替代。
