# 概率校准验收：2026-09-17

本次核对**已给定“对手持有随机合法牌、所有人打到摊牌”假设时的数学概率**。没有训练或修改手机概率，没有把合成牌局结果当真人胜率，没有把一位整数的显示精度当模型准确度。

## 方法与复现

新增 `tools/check_probability_calibration.swift` 和 `tools/run_probability_calibration.sh`，只依赖 Swift 标准库、Foundation 和项目的 Cards / Ranges / Equity 三个源文件。无需录屏、账号、设备或网络。

```bash
# 首轮：12 格，每格 500 个独立牌局，每次预测 2048 次 MC
tools/run_probability_calibration.sh --deals-per-cell 500 --samples 2048 \
  > random-range-calibration.json

# 一次预先固定规模的新种子诊断复验；不是训练或调参
tools/run_probability_calibration.sh --deals-per-cell 5000 --samples 512 \
  --truth-seed 5345434f4e445452 --prediction-seed 5345434f4e445052 \
  > random-range-replication.json
```

- 覆盖 2、6、8 人（包括本人），以及翻前、翻牌、转牌、河牌，共 12 格。每格使用不同完整牌局；同一手的多个街道没有重复计为独立样本。
- 标签由独立 PCG32 生成器和无偏 Fisher–Yates 洗牌产生；生产引擎使用 SplitMix64。预测种子不依赖真实对手牌、真实后续公共牌或真值随机数输出。
- 标签牌型使用独立“五张分类＋七张选五的 21 个组合穷举”评估器，不调用生产牌型、抽样或分池函数。额外逐对比较标签与生产评估器的牌型排序。
- 预测只能看本人底牌和当前公共牌前缀。所有未知对手范围为 `HandRange.random`，看不到真实对手牌和未发公共牌。
- 独赢、平分是两个不同的二元事件，报告 Brier 分数。份额标签为 `0 / 1/k / 1`，报告分数标签的平方误差及经验残差方差；没有把份额当成独赢或伯努利事件。
- 10 个固定概率箱输出预测均值、观察均值、样本量、区间。Brier 同时反映校准、区分度和事件自身随机性，不能单看较低分数就宣称更准。[scikit-learn 官方校准文档](https://scikit-learn.org/1.8/modules/calibration.html)
- 首轮出现少数名义 95% 分格区间不包含 0 后，保留首轮所有结果，只增加一次固定 60000 局、独立种子的诊断复验。没有更换模型、调参或反复挑到好看为止。

## 实际结果

两个报告都保存了完整人数/街道分格、事件数和分箱，不仅保存总平均。

| 独立样本 | 指标 | 预测均值 | 观察均值 | 预测减观察的近似 95% 区间 |
| --- | --- | ---: | ---: | --- |
| 首轮 6000 局 | 独赢 | 25.091% | 24.983% | -0.778～+0.994 个百分点 |
| 首轮 6000 局 | 平分 | 2.995% | 2.933% | -0.353～+0.477 个百分点 |
| 首轮 6000 局 | 摊牌份额 | 26.500% | 26.354% | -0.734～+1.026 个百分点 |
| 诊断复验 60000 局 | 独赢 | 25.019% | 24.870% | -0.133～+0.432 个百分点 |
| 诊断复验 60000 局 | 平分 | 3.099% | 3.172% | -0.207～+0.062 个百分点 |
| 诊断复验 60000 局 | 摊牌份额 | 26.479% | 26.348% | -0.148～+0.412 个百分点 |

首轮独赢 / 份额的 Brier / 平方误差分别为 `0.122643 / 0.120929`，诊断复验为 `0.124695 / 0.122431`。两轮使用不同牌局及抽样数，**不能据此比较成“第二轮模型更好或更坏”**，模型根本没有变化。

诊断复验按人数拆分：

| 人数 | 独立牌局 | 独赢：预测 / 观察 | 摊牌份额：预测 / 观察 |
| --- | ---: | ---: | ---: |
| 2 | 20000 | 47.769% / 47.615% | 49.821% / 49.685% |
| 6 | 20000 | 15.925% / 15.580% | 17.126% / 16.768% |
| 8 | 20000 | 11.364% / 11.415% | 12.491% / 12.590% |

首轮单挑翻前的 500 局中只出现 9 次平分，预测 4.063%、观察 1.8%，名义偏差区间没有包含 0。一次独立复验的同格 5000 局出现 220 次平分，预测 4.038%、观察 4.4%。这支持“首轮稀有事件的小样本波动”的解释，没有依据据此改低生产平分概率。

### 多重比较处理

12 格 × 3 指标共有 **36 个均值比较**。普通 95% 区间只作描述，不能把任何一格越界直接认定为缺陷。

另外报告固定 family=36 的 Bonferroni–Hoeffding 同时 95% 界：残差 `r = prediction - outcome ∈ [-1,1]`，均值半宽为 `sqrt(2 * log(2 * 36 / 0.05) / n)`。其范围很宽，首轮每格约 ±17.06 个百分点，复验约 ±5.39 个百分点；两轮全部 36 个区间都含 0。**这仅表示未拒绝零偏差，不能证明模型准确到该范围或没有更小的偏差。**该同时性声明不涵盖额外分箱和其他汇总。[Berkeley Hoeffding 讲义](https://people.eecs.berkeley.edu/~bartlett/courses/281b-sp08/12.pdf)

事件总数和上述同时界在运行结束后由保留汇总直接补充，报告的 `postprocessing` 字段明确记录此事；没有重新采样或更改预测值。最新工具可以直接生成相同字段。有限分箱指标 ECE 本身有采样偏差，不能单独当作验收门槛。[JMLR 校准指标研究](https://www.jmlr.org/papers/v23/22-0658.html)

### 独立规则与抽样检查

- 主评估：首轮 `12,288,000` 个 MC 样本、诊断复验 `30,720,000` 个；全部完成预定样本数，没有因墙钟截止提前返回。
- 独立完整牌型排序：两轮分歧均为 0。
- 单挑河牌：另一个固定真值种子产生 16 个局面，每个枚举 990 个对手组合；三项概率与生产精确算法全部一致，最大数值误差约 `1.60e-16`。
- 确定分池：公共牌皇家同花顺下的 2、6、8 人，验证独赢 `0`、平分 `1`、份额 `1/人数`，全部通过（记录在诊断复验报告）。
- 每格前两个局面再换独立 MC 种子，共 24 对。2048 样本时，两次份额估计差值的 RMS 为 **1.223 个百分点**、最大 **3.451 个百分点**；512 样本时为 **2.556 / 7.910 个百分点**。这些是少量诊断输入的差异，不能外推成所有手机局面的统一误差条。
- 抽样区间重叠检查全部满足；这没有消除抽样噪声，也没有评价真实人的范围误差。

运行耗时分别约 28.8 秒和 80.9 秒，属于本机离线执行记录；没有采用安静主机计时协议，**不作为手机实时性能基准**。

## 哪些已核对，哪些仍不能宣称

在本次随机牌假设、人数和街道分布下，未观察到稳定的总体概率偏移；精确 oracle 和牌型排序检查也没有发现缺陷。因此没有给本来正确的随机数学强行套一层校准映射。

这些结果**不覆盖**真人行动后的范围、谁会弃牌、跟注/加注概率、下注节奏、OCR 误读、人数识别、第三盲行动历史重建、主池/边池资格、筹码 EV 或长期真人收益。现实中“看到某人下注后他的牌更强”属于条件范围/行为模型问题，不能从均匀随机牌的标签里学会。

真人校准需要可核实的数据边界：只用最终亮牌训练会产生选择偏差，弃掉而未亮的牌不能伪造标签；动作后同一手多街道必须按整手分组；训练/验证/测试需要按玩家及时间隔离；参数挑选只能用训练/验证集。未使用的独立测试没有改善时，不应晋升。策略 EV 还要独立核对下注规则和对手响应，不能由独赢百分比直接换算。

当前 `CoachModel.refreshFullDecision` 使用 256 的策略计算样本预算；这和本工具对 `EquityEngine` 的 512/2048 样本审计不是同一估计器，**不能直接复制上面误差数值**。但若要给用户稳定的整数概率，应另行检查真实路径的有效样本数、跨种子波动、时间截止和重复局面的稳定性。
